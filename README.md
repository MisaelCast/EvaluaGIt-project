# EvaluaGit

EvaluaGit es una plataforma web para analisis academico de repositorios Git.

El objetivo del proyecto es ayudar a profesores a revisar proyectos de programacion de forma mas simple, automatizando revisiones basicas sobre estructura, actividad Git, requerimientos y similitud entre repositorios.

## Stack tecnologico

* Frontend: Vue 3 + Vite + TypeScript
* Backend: FastAPI
* Base de datos: PostgreSQL
* Auth futura: Supabase Auth con Google OAuth

## Objetivo MVP

El MVP debe permitir que profesores creen proyectos, registren requerimientos, ejecuten analisis y revisen resultados. Tambien debe permitir que alumnos inicien sesion, vinculen su repositorio de GitHub y consulten su propio analisis.
